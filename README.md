# Chaotic More Like This

Initial foundation plugin for Jellyfin 10.11.11.

## Features

- Serverwide admin settings.
- Deterministic chaos tags.
- Applies to selected item types.
- Defaults to Movies and Series.
- Cleanup support.
- Per-user preference storage.
- Admin and user plugin pages.
